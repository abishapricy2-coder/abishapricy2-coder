## Projects

### Smart Campus Energy Prediction

Predicts the next hour of campus energy use and shows it on a live dashboard. Readings come from a built-in simulator or from ESP32 and Wokwi devices. The model is evaluated with MAE, RMSE and R² on a held-out test set, and the training data is labelled as simulated.

```
ESP32 or simulator  →  FastAPI  →  MySQL  →  DNN prediction  →  React dashboard
```

[View code](https://github.com/abishapricy2-coder/smart-campus-energy-prediction)

### Traffic-AI

Predicts vehicle count from the hour of day, day of week, weather index and holiday indicator. The training pipeline validates data, scales features, saves the model and can generate synthetic datasets for testing.

```
hour, day, weather, holiday  →  validation  →  scaling  →  regression  →  vehicle count
```

[View code](https://github.com/abishapricy2-coder/Traffic-AI)
